# side-monitor

A Claude Code side panel that shows:

- this session's share of the weekly usage limit;
- the context fill, with a `Cmpct now` button and automatic compaction at 85%;
- every running agent and shell, with its latest output line. Press `[v]` on a section's divider to expand it to the full panel height, and `[^]` to collapse it.

Open the panel with `/monitor`.
